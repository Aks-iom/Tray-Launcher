# TrayLauncher

Крошечная утилита для Windows, которая живёт в трее, запускает указанную программу и показывает цветом иконки, запущена ли она сейчас.

> Программа изначально делалась для **Zapret-discord-youtube** (чтобы запускать и останавливать его из трея и видеть, что он работает), но подойдёт для любой программы или скрипта. Используйте как хотите.

## Возможности

- Работает **только в трее**: без окон и без значка в панели задач
- Запускает файл, путь к которому указан в `launch.txt` рядом с программой (`.exe`, `.bat`, `.lnk` и т. д.)
- Иконка показывает состояние:
  - 🟢 зелёная: приложение запущено
  - 🔴 красная: не запущено
  - ⚪ серая: файл из `launch.txt` не найден
- **Левый клик** по иконке: запустить, а если уже запущено, остановить
- **Правый клик**: меню (Запустить / Остановить / Автозапуск / Открыть `launch.txt` / Выход)
- **Автозапуск с Windows** включается сам при первом запуске, отключается в меню
- Не требует установки, .NET и прочих зависимостей
- Только один экземпляр: повторный запуск ничего не делает

## Минимальное потребление ресурсов

- Нативный Win32 на C, без .NET, без WinForms, без стандартной библиотеки C: exe около 45 КБ
- Пока приложение запущено, **опроса нет**: Windows сама сообщает о завершении процесса
- Пока не запущено, лёгкий опрос раз в 2 секунды (период меняется константой `POLL_MS`)
- `launch.txt` перечитывается только при изменении файла
- В простое поток спит, нагрузка на процессор 0%
- Иконки рисуются один раз при старте, после инициализации рабочий набор памяти обрезается

## Использование

1. Скачайте `TrayLauncher.exe` (раздел Releases) или соберите сами, см. ниже.
2. Положите `TrayLauncher.exe` и `launch.txt` в одну папку.
3. Впишите в `launch.txt` путь к нужной программе и название процесса с новой строки (необязательно)
4. Запустите `TrayLauncher.exe`. Иконка появится в трее (возможно, в скрытых значках `^`).

Если `launch.txt` не существует, при первом запуске он создаётся с примером (`notepad.exe`).

## Формат `launch.txt`

```
# Строки, начинающиеся с #, игнорируются
# Строка 1: путь к файлу/программе (абсолютный или относительный к папке TrayLauncher.exe)
# Строка 2 (необязательно): имя процесса для проверки, без .exe
C:\Programs\MyApp\myapp.exe
```

- Путь может быть относительным (отсчёт от папки с `TrayLauncher.exe`) и содержать переменные окружения, например `%APPDATA%\app\app.exe`.
- Кавычки вокруг пути необязательны.
- По умолчанию состояние определяется по имени процесса, совпадающему с именем файла (`myapp.exe` → процесс `myapp.exe`). Если вы запускаете `.bat`, ярлык или лаунчер, у которого процесс называется иначе, укажите имя процесса **второй строкой**.
- Изменения в `launch.txt` подхватываются без перезапуска программы.
- Кодировка: UTF-8 или UTF-16.

## Пример для Zapret-discord-youtube

Для Zapret-discord-youtube запуск идёт через `.bat`-файл, а сама работа выполняется процессом `winws.exe`, поэтому именно его нужно указать для индикатора:

```
zapret-discord-youtube\general.bat
winws
```

(путь подставьте свой, `general.bat` можно заменить на любой другой вариант из вашей сборки)

Нюансы:

- Zapret обычно требует права администратора. При запуске из трея Windows может показать окно UAC.
- Если `winws.exe` работает с правами администратора, а `TrayLauncher` запущен без них, остановка из меню может не сработать. В таком случае запускайте `TrayLauncher.exe` от имени администратора. Индикатор состояния при этом продолжит работать, но использует опрос вместо ожидания события.

## Сборка из исходников

Нужен компилятор MinGW-w64 (например, через [MSYS2](https://www.msys2.org/)) в `PATH`:

```bat
gcc -Os -fno-math-errno -fno-ident -fno-asynchronous-unwind-tables ^
    -ffunction-sections -fdata-sections -mwindows -nostartfiles ^
    -Wl,-e,entry -Wl,--gc-sections -s ^
    -o TrayLauncher.exe TrayLauncher.c ^
    -luser32 -lshell32 -ladvapi32 -lkernel32
```

Или запустите `build.bat`.
